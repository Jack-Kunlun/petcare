# Admin 侧栏彩色 Logo 设计

## 目标

将后台左侧导航顶部的方形品牌标识替换为品牌系统中的彩色 SVG，使后台首页及所有共用侧栏的页面更具品牌辨识度。

## 范围

- 从 `docs/10-brand-system/deliverables/logo/svg/petcare-symbol-color.svg` 复制彩色标识到 Admin 的 `src/assets/brand` 运行时资源目录。
- 为 `BrandLogo` 增加 `color` 变体，并保持现有 `reverse` 与 `stacked-reverse` 变体行为不变。
- 仅将 `Sidebar` 顶部标识切换为 `color` 变体。
- 保持侧栏标识现有 `40px × 40px` 尺寸、可访问名称、文字排版和深色背景不变。
- 登录页继续使用反白品牌标识，不在本次范围内调整。

## 设计选择

彩色标识直接显示在深色侧栏上，不增加浅色底板，也不改用横向组合 Logo。这样既能增强色彩表现，又不会造成品牌文字重复或挤占导航空间。

## 组件边界

- `BrandLogo` 继续负责品牌资源变体与渲染。
- `Sidebar` 只声明需要使用的 `color` 变体，不直接导入品牌图片。
- 品牌源文件保留在文档交付目录；Admin 运行时目录只保存实际使用的资源。

## 验证

- 更新 `BrandLogo` 单元测试，确认 `color` 变体解析到彩色 SVG。
- 更新 `Sidebar` 单元测试，确认侧栏使用彩色标识并保留可访问名称与尺寸。
- 运行 Admin lint、相关单元测试、样式策略与生产构建。
- 核对运行时彩色 SVG 与品牌源文件 SHA-256 一致。

## 非目标

- 不修改登录页 Logo。
- 不修改浏览器图标、登录背景或其他品牌资源。
- 不调整侧栏布局、菜单权限、交互动效和响应式行为。
