# PetCare 登录页单页重设计规格

## 范围

- 仅重设计 Figma 文件 `mwpHHcx0VAutpPTIhGYGqC` 中 `Auth/Sign In/Default`（当前节点 `165:2`）。
- 不修改其他 Auth 状态、首页、组件库、变量或后续业务页面。
- 画板基准为 `375×812`，同时保证内容在 360px 宽度下不会出现单字孤行或横向溢出。

## 视觉方向

- 采用“温暖真实摄影”方向，整体气质为温暖、可信、克制。
- 使用现有批准的 PetCare 宠物照护摄影与 Logo，不重绘、不拉伸、不重着色。
- 摄影承担情绪表达；Primary Blue 只用于核心登录操作；背景使用中性浅色。
- 不使用厚重悬浮卡、大面积高饱和渐变或无语义装饰图标。

## 页面结构

1. 顶部安全区：保留系统状态区域，不放置可点击控件。
2. 品牌与摄影区：约占页面高度 42%；使用批准摄影，保持原始比例和安全区。Approved Logo 小尺寸展示，不作为巨大主视觉。
3. 内容区：摄影以柔和过渡进入浅色背景，不使用明显割裂的白色大卡片。
4. 标题：居中单行 `让每一次照护，都更安心`，24px/32px、Bold；宽度不得造成单字孤行。
5. 副文案：居中 `连接值得信赖的照护者，安心记录每一次陪伴。`，14px/22px，使用次级文本色。
6. 主操作：唯一主按钮 `微信登录并授权手机号`，宽343px、高52px；不显示默认 Plus 或 Chevron。
7. 协议说明：紧邻按钮下方，明确服务协议与隐私政策；可点击文本保持可识别。
8. 底部信任文案：低强调、用户可理解；不出现 `示例状态`、safe-area、权限实现等技术说明。

## 布局与质量约束

- 页面左右主边距16px，文本区域采用 Auto Layout；不使用为当前文案硬编码的脆弱绝对定位。
- 标题优先保持单行；若360px校验无法保持单行，则只能按语义断为 `让每一次照护，` / `都更安心`，禁止最后一行单字。
- 触控目标不小于44×44px；主按钮必须为真实组件实例、scale factor 1。
- 所有实际渲染文本须逐层检查，不能只验证 component properties。
- 页面中不得存在裁切文字、占位模板文案、组件默认图标、横向溢出或脱离实例。

## 验收

- 截图检查 375×812 整页、标题区、摄影与内容过渡、主按钮和协议区。
- 结构检查：1个主按钮、0个底部TabBar、0 detached instances、0横向溢出。
- 字体检查：中文使用已批准的 Noto Sans SC 设计样式；Logo保持批准图稿。
- 仅在用户确认本页后，才进入下一个页面。
