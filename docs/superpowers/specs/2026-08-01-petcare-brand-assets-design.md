# PetCare 官网首发品牌资产包设计规格

> 日期：2026-08-01  
> 状态：已确认  
> 依据：`docs/10-brand-system/PetCare-Brand-Book-v1.0.md`

## 1. 目标

基于《PetCare Brand Book v1.0》和用户批准的实际 Logo 艺术稿 `docs/10-brand-system/assets/petcare-brand-positioning-logo-v1.png`，交付一套可直接用于品牌官网、小程序和常规数字传播场景的首发品牌资产。该文件是批准的源艺术稿；从其中直接提取的主锁定版和完整锁定版透明 PNG 是生产视觉母版。Logo 工作仅做忠实拆分、矢量重建与格式归一化，不进行重新设计、再解释、简化或风格优化。

## 2. 设计基线

- 品牌主张：每一次托付，都值得信赖。
- 品牌气质：可信赖、温暖、专业、克制、现代。
- 主色：`#4A6CF7`。
- 辅色：`#5BC8AF`。
- 强调色：`#F6B343`。
- 主文字色：`#1F2937`。
- 浅色背景：`#F8FAFC`。
- Logo 视觉基线：一比一保留实际艺术稿的圆角丝带房屋/盾牌、顶部四格窗、左犬右猫剪影、相互遮挡与负空间，以及原 `PetCare` 字标比例和间距。
- Logo 色彩基线：使用实际艺术稿的 `#4A6CF7` 蓝色与 `#5BC9B9` 薄荷色关系；当风格偏好与实际艺术稿冲突时，以实际艺术稿为准。
- 摄影语言：真实家庭、自然光、照护后的安心状态、充足留白。

## 3. 交付范围

### 3.1 Logo 套件

交付批准稿直接提取的透明 PNG 视觉母版、可编辑且与母版哈希绑定的像素路径 SVG 伴随版与常用派生 PNG。主锁定版保持批准稿中的 Symbol 垂直位于 `PetCare` 上方；字标直接来自批准的实际艺术稿，不使用 `<text>`、外部字体或替代字形，不得创建横版替代构图。PNG 是唯一视觉权威；SVG 仅用于忠实的数字伴随交付，不构成重新设计或新的几何母版。

| 资产             | 格式              | 用途                                          |
| ---------------- | ----------------- | --------------------------------------------- |
| 批准稿主锁定版   | 透明 PNG          | 生产视觉母版：Symbol + `PetCare`              |
| 批准稿完整锁定版 | 透明 PNG          | 生产视觉母版：含英文标语与中文口号            |
| 堆叠版 Logo      | SVG、PNG 1x/2x/3x | 正式数字页面；保持批准稿比例与尺寸关系        |
| Symbol           | SVG、PNG 1x/2x/3x | 图标、加载、角标                              |
| 深色版           | SVG、PNG          | 浅色背景                                      |
| 单色版           | SVG、PNG          | 单色印刷、受限环境                            |
| 反白版           | SVG、PNG          | 深色或摄影背景                                |
| Favicon          | SVG、PNG、ICO     | 浏览器标签页                                  |
| App/小程序图标   | PNG               | 1024、512、192、180、144、128、96、64、48、32 |

Logo 图形以几何路径输出，字标使用确定字体与轮廓化版本。所有版本遵循 0.25H 安全区；页面页眉图形高度默认 32px，品牌展示默认 48px，最大 64px。

### 3.2 官网轮播主视觉

交付三套无文字摄影主视觉。Logo、标题、说明和按钮全部由前端叠加，避免生成式图片文字错误并支持多语言与响应式布局。

| 编号    | 主题     | 场景                             | 主体位置 | 文案安全区 |
| ------- | -------- | -------------------------------- | -------- | ---------- |
| Hero 01 | 安心托付 | 猫与狗在明亮现代家庭中安静休息   | 右侧 55% | 左侧 40%   |
| Hero 02 | 专业照护 | 整洁喂养区域、饮水与服务记录细节 | 左侧 55% | 右侧 40%   |
| Hero 03 | 社区陪伴 | 宠物在自然光客厅中形成温暖互动   | 右侧 55% | 左侧 40%   |

每套输出：

- 官网原图：`1920×720` PNG/WebP。
- 小程序裁切：`750×340` PNG/WebP。
- Open Graph 裁切：`1200×630` PNG/WebP。
- 不含文字、按钮、Logo、水印或不可替换装饰。

### 3.3 品牌辅助元素

- 蓝绿品牌渐变：线性、径向、浅色背景三种 SVG/CSS 定义。
- 柔和光晕：透明 SVG，不承载语义信息。
- 连接线纹理：稀疏、低对比度、可平铺 SVG。
- 品牌角标：Symbol-only 与 `Trusted Companion` 两种 SVG。
- 轮播遮罩：左文案区、右文案区和底部渐隐三种 CSS/SVG 方案。
- 通用占位背景：浅色、深色各一套，适用于登录页和内容加载状态。

## 5. 生成与制作方法

### Logo

Logo 从批准的实际 Logo 艺术稿直接裁切并确定性去除近白背景，生成主锁定版和完整锁定版两个透明 PNG 生产视觉母版。SVG 使用确定性像素行路径忠实记录主锁定版，并携带生产母版 SHA-256 与版本化生成契约，仅作为可编辑、可审计的数字伴随输出；其具备 `viewBox` 与可访问 `<title>`，不得包含 `<text>`、嵌入位图、外部 CSS、远程字体或 URL。实际艺术稿的堆叠构图、轮廓、窗格、犬猫比例、方向、重叠、负空间、蓝薄荷渐变关系以及字标比例优先于任何几何简化或风格偏好。该 SVG 不宣称是独立 Bézier 几何母版；超大幅印刷、雕刻或其他需要平滑几何曲线的场景，必须基于实际艺术稿另行进行品牌审批，不得自行重绘。

### 轮播图

轮播图使用图像生成工具制作真实摄影素材。提示词固定品牌场景、主体位置、色温和安全区；每次生成后检查宠物结构、环境真实性、空白区域和裁切兼容性。图像中不得生成文字或 Logo。

### 后处理

- 保留 PNG 母版，官网同时输出 WebP。
- 使用高质量缩放生成小程序与社交媒体裁切版。
- 不进行过度锐化、强 HDR 或高饱和滤镜处理。
- 为每张图记录最终提示词、用途和建议 alt text。

## 6. 官网使用规范

- Logo 在桌面页眉默认高度 32px，移动端默认 28px。
- Hero 文案最大宽度 560px，必须置于设计指定安全区。
- 图片上叠加文字时，正文对比度达到 WCAG AA。
- 轮播自动切换间隔不少于 5 秒，并提供暂停和手动切换能力。
- 尊重 `prefers-reduced-motion`，减少动态效果时取消自动播放。
- 图片使用 `<picture>` 或等效响应式加载方案，提供 WebP 和 PNG 回退。
- 装饰图片使用空 alt；承载场景意义的图片使用资产清单中的建议 alt text。

## 7. 验收标准

### Logo

- SVG 无嵌入位图、无远程依赖、无错误文字。
- 生产主锁定版为批准稿直接提取的 Symbol 上、`PetCare` 下的堆叠构图；不得提交横版替代构图。
- 完整锁定版保留批准稿中的 `Trusted Pet Companion Platform` 与中文口号；主锁定版不含两者。
- 在批准的 `330×260` 尺寸直接渲染提交后的伴随 SVG，并将生产 PNG 与批准稿做逐像素比较；外轮廓、窗格、犬猫轮廓、渐变方向、字标宽度/字重/间距、垂直间距和 Symbol-to-wordmark 比例不得产生可见偏离。生产 PNG 必须与透明视觉母版逐像素一致。
- 16px、24px、32px、48px 和 64px 尺寸均可辨识。
- 彩色、深色、单色和反白版本结构一致。
- 安全区、背景适配和文件命名符合 Brand Book。

### 轮播图

- 三个主题清晰且风格一致。
- 猫狗身体结构、毛发、光影和空间关系自然。
- 指定文案安全区干净，没有关键主体进入。
- 桌面、小程序和社交裁切均无关键内容丢失。
- 不含文字、乱码、生成式 Logo、水印和医疗化元素。

### 交付质量

- 目录完整，README 说明用途、尺寸、色值、alt text 和提示词。
- PNG、WebP、SVG 均可打开，尺寸与透明通道正确。
- 不覆盖用户批准的实际 Logo 艺术稿；两个透明 PNG 生产视觉母版可由确定性提取脚本复现。

## 8. 非目标

- 本轮不制作完整品牌官网页面或前端轮播组件。
- 本轮不重新定义品牌定位、品牌色或品牌口号。
- 本轮不制作印刷品、服装、包装或线下门店物料。
- 本轮不重新设计、再解释、简化或风格优化批准的实际 Logo 艺术稿。

## 9. 当前小程序应用基准（v45）

本规格的资产消费方式以最新小程序原型为准，页面信息结构不因品牌色更新而改变：

- 主操作、选中 Tab 和主链接使用品牌蓝 `#4A6CF7`。
- 陪伴、完成、成长和进度反馈使用产品辅助色 `#5BC8AF`；`#5BC9B9` 仅保留给批准 Logo artwork。
- 悬赏价格和有限度提示使用琥珀强调色 `#F6B343`。
- 页面背景、卡片、正文、辅助文字和边框使用 `#F8FAFC`、`#FFFFFF`、`#1F2937`、`#667085`、`#E6EAF0`。
- 小程序 5 个主 Tab 固定为 `/`、`/bounty`、`/community`、`/messages`、`/profile`；Logo 使用 Symbol 资产，登录与启动场景使用 stacked Logo。
- 轮播图继续使用 `750×340` 小程序资产，图片不内嵌 Logo、标题或 CTA，所有文案由页面层叠加。
