# PetCare 官网首发品牌资产包设计规格

> 日期：2026-08-01  
> 状态：已确认  
> 依据：`docs/10-brand-system/PetCare-Brand-Book-v1.0.md`

## 1. 目标

基于《PetCare Brand Book v1.0》和用户确认的品牌定位图，交付一套可直接用于品牌官网、小程序和常规数字传播场景的首发品牌资产。资产必须保持“连接、信任、陪伴”的品牌核心，同时满足响应式裁切、前端叠加文案、无障碍和长期维护需求。

## 2. 设计基线

- 品牌主张：每一次托付，都值得信赖。
- 品牌气质：可信赖、温暖、专业、克制、现代。
- 主色：`#4A6CF7`。
- 辅色：`#5BC8AF`。
- 强调色：`#F6B343`。
- 主文字色：`#1F2937`。
- 浅色背景：`#F8FAFC`。
- Logo 结构基线：家形守护轮廓、爱心关系、猫狗陪伴剪影。
- 摄影语言：真实家庭、自然光、照护后的安心状态、充足留白。

## 3. 交付范围

### 3.1 Logo 套件

交付可编辑 SVG 与常用 PNG，不使用生成式图片中的文字作为正式字标。

| 资产           | 格式              | 用途                                          |
| -------------- | ----------------- | --------------------------------------------- |
| 标准横版 Logo  | SVG、PNG 1x/2x/3x | 官网页眉、正式页面                            |
| 紧凑横版 Logo  | SVG、PNG 1x/2x/3x | 窄页眉、移动端                                |
| Symbol         | SVG、PNG 1x/2x/3x | 图标、加载、角标                              |
| 深色版         | SVG、PNG          | 浅色背景                                      |
| 单色版         | SVG、PNG          | 单色印刷、受限环境                            |
| 反白版         | SVG、PNG          | 深色或摄影背景                                |
| Favicon        | SVG、PNG、ICO     | 浏览器标签页                                  |
| App/小程序图标 | PNG               | 1024、512、192、180、144、128、96、64、48、32 |

Logo 图形以几何路径输出，字标使用确定字体与轮廓化版本。所有版本遵循 0.25H 安全区；页面页眉图形高度默认 32px，品牌展示默认 48px，最大 64px。

### 3.2 官网轮播主视觉

交付三套无文字摄影主视觉。Logo、标题、说明和按钮全部由前端叠加，避免生成式图片文字错误并支持多语言与响应式布局。

| 编号    | 主题     | 场景                             | 主体位置 | 文案安全区 |
| ------- | -------- | -------------------------------- | -------- | ---------- |
| Hero 01 | 安心托付 | 猫与狗在明亮现代家庭中安静休息   | 右侧 55% | 左侧 40%   |
| Hero 02 | 专业照护 | 整洁喂养区域、饮水与服务记录细节 | 左侧 55% | 右侧 40%   |
| Hero 03 | 社区陪伴 | 宠物在自然光客厅中形成温暖互动   | 右侧 55% | 左侧 40%   |

每套输出：

- 官网原图：`1920×720` PNG/WebP。
- 小程序裁切：`750×340` PNG/WebP。
- Open Graph 裁切：`1200×630` PNG/WebP。
- 不含文字、按钮、Logo、水印或不可替换装饰。

### 3.3 品牌辅助元素

- 蓝绿品牌渐变：线性、径向、浅色背景三种 SVG/CSS 定义。
- 柔和光晕：透明 SVG，不承载语义信息。
- 连接线纹理：稀疏、低对比度、可平铺 SVG。
- 品牌角标：Symbol-only 与 `Trusted Companion` 两种 SVG。
- 轮播遮罩：左文案区、右文案区和底部渐隐三种 CSS/SVG 方案。
- 通用占位背景：浅色、深色各一套，适用于登录页和内容加载状态。

## 5. 生成与制作方法

### Logo

Logo 使用确定性 SVG 制作，根据已确认图形重新构建，避免 AI 生成文字、路径不闭合或小尺寸失真。SVG 需具备 `viewBox`，不依赖外部 CSS，不引用远程字体。

### 轮播图

轮播图使用图像生成工具制作真实摄影素材。提示词固定品牌场景、主体位置、色温和安全区；每次生成后检查宠物结构、环境真实性、空白区域和裁切兼容性。图像中不得生成文字或 Logo。

### 后处理

- 保留 PNG 母版，官网同时输出 WebP。
- 使用高质量缩放生成小程序与社交媒体裁切版。
- 不进行过度锐化、强 HDR 或高饱和滤镜处理。
- 为每张图记录最终提示词、用途和建议 alt text。

## 6. 官网使用规范

- Logo 在桌面页眉默认高度 32px，移动端默认 28px。
- Hero 文案最大宽度 560px，必须置于设计指定安全区。
- 图片上叠加文字时，正文对比度达到 WCAG AA。
- 轮播自动切换间隔不少于 5 秒，并提供暂停和手动切换能力。
- 尊重 `prefers-reduced-motion`，减少动态效果时取消自动播放。
- 图片使用 `<picture>` 或等效响应式加载方案，提供 WebP 和 PNG 回退。
- 装饰图片使用空 alt；承载场景意义的图片使用资产清单中的建议 alt text。

## 7. 验收标准

### Logo

- SVG 无嵌入位图、无远程依赖、无错误文字。
- 16px、24px、32px、48px 和 64px 尺寸均可辨识。
- 彩色、深色、单色和反白版本结构一致。
- 安全区、背景适配和文件命名符合 Brand Book。

### 轮播图

- 三个主题清晰且风格一致。
- 猫狗身体结构、毛发、光影和空间关系自然。
- 指定文案安全区干净，没有关键主体进入。
- 桌面、小程序和社交裁切均无关键内容丢失。
- 不含文字、乱码、生成式 Logo、水印和医疗化元素。

### 交付质量

- 目录完整，README 说明用途、尺寸、色值、alt text 和提示词。
- PNG、WebP、SVG 均可打开，尺寸与透明通道正确。
- 不覆盖用户提供的 v1.0 参考图。

## 8. 非目标

- 本轮不制作完整品牌官网页面或前端轮播组件。
- 本轮不重新定义品牌定位、品牌色或品牌口号。
- 本轮不制作印刷品、服装、包装或线下门店物料。
- 本轮不把生成式图片直接视为 Logo 矢量母版。
