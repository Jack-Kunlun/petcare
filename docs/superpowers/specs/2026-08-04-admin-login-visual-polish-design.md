# 后台登录页视觉与交互修正设计

## 背景

现有后台登录页已具备品牌 Logo、密码/验证码登录切换和验证码发送反馈，但存在以下体验问题：背景层次单一，验证码区域控件尺寸不一致，品牌区深色且内容分布空洞，Logo 在不同位置的实际显示清晰度不足，登录卡片文案与颜色层级不统一，登录方式切换会造成卡片高度变化。

## 目标

在不改变登录接口、认证逻辑、验证码校验和路由行为的前提下，完成以下视觉修正：

1. 使用蓝紫渐变品牌区和低对比装饰层，提升背景层次。
2. 统一验证码输入框、验证码图片和发送按钮的高度、圆角、间距及状态反馈。
3. 优化左侧品牌文案的层级与垂直分布，减少空洞感并保持高对比度。
4. 统一 Logo 的显示尺寸、对象适配和解码属性，减少布局压缩造成的模糊观感。
5. 统一登录卡片文字颜色和品牌色层级。
6. 固定登录表单内容区高度；密码/验证码切换时增加内容淡入与上移动效，并支持 reduced-motion 降级。

## 设计方案

采用“现有 SVG + CSS 视觉层”方案，不新增图片处理链，不替换批准的品牌资产。

### 品牌区

- 背景使用品牌蓝到靛蓝再到深色的渐变。
- 增加两个静态低对比光晕和细网格纹理，装饰层不承载信息，不参与交互。
- 文案按品牌眉题、主标题、说明和服务标签分层排列。
- 保证文字对比度，装饰层在 reduced-motion 下保持静态。

### 表单区

- 密码和验证码模式共用固定最小高度容器，避免切换造成卡片跳动。
- 所有表单控件采用同一高度和圆角；验证码图片区、输入框、发送按钮使用统一 `h-12` 规格。
- 发送按钮使用固定宽度，发送中和倒计时文案不会改变布局。
- 使用现有品牌 token，避免在组件中新增原始颜色。

### 动效与可访问性

- 模式指示滑块继续使用 220ms 平移动效。
- 面板内容使用 220ms 的透明度与垂直位移动效。
- 全局 reduced-motion 规则关闭或最小化过渡和动画。
- 保留语义 label、tab、tabpanel、焦点环、禁用状态和 aria-live 错误提示。

### Logo

- `BrandLogo` 增加同步解码和明确的可替换布局属性。
- 登录页使用更大的 stacked reverse Logo；侧栏继续使用 symbol Logo，但固定宽高并保持 `object-contain`。
- 不修改批准 SVG 内容。

## 范围边界

- 仅修改 Admin 登录页、BrandLogo 组件及其测试/必要的样式 token。
- 不修改认证 API、验证码 API、路由、权限判断或服务端逻辑。
- 不新增第三方依赖、不引入 PNG/WebP 构建链。

## 验收标准

- 375px、768px、1024px、1440px 宽度下无横向溢出，表单切换时卡片高度稳定。
- 密码登录和验证码登录的输入控件高度一致；验证码行三项控件视觉对齐。
- 登录页品牌区有明显层次但文字保持清晰可读。
- 登录页、侧栏 Logo 均使用批准 SVG，并具备明确尺寸和 `decoding` 属性。
- 现有登录、验证码发送、验证码刷新、错误和 loading 测试全部通过。
- Admin 类型检查、Vitest、ESLint、Vite 构建和样式策略检查通过。
