# 官网首页内容闭环设计

## 目标

把新版首页 `HomeExperience` 中的六组内容接入现有 Website Content 草稿、预览、发布、历史和公开读取链路；不新增内容系统、数据库表或依赖。

## 设计

- 新增固定区块类型 `home_experience`。一个区块承载服务卡片、服务流程、照护记录示例、信任细节、社区内容和品牌故事，保持它们作为同一首页体验整体发布。
- 图片继续保存 `assetId + altText`，公共与预览接口批量解析为安全公开素材；`assetId = null` 时使用官网内置品牌图。
- 首页模板顺序为 `hero`、`trust_evidence`、`service_modes`、`home_experience`、`home_cta`。Hero 与 `home_experience` 为必需区块，避免新版快照关闭动态区块后被误判为旧快照并展示静态降级内容。
- 旧首页快照保持不可变。服务端只兼容缺少 `home_experience` 的旧模板；Admin 读取旧草稿时返回补齐后的可编辑投影，第一次保存即创建包含新区块的新草稿修订。
- 旧发布版本或未升级预览继续使用代码内 `HomeExperience` 降级内容；新草稿保存并发布后改由同名动态区块渲染。

## 边界

- 不开放新增、删除、换型或拖拽排序。
- 不把服务记录示例连接到真实订单；它只是可编辑的官网演示内容。
- 社区卡片仍统一链接宠物课堂列表，不引入文章选择器。
- 不修改历史版本，也不做 Prisma schema migration。

## 验收

1. Admin 可编辑全部六组文案、链接、图片和固定条目，并保存、预览、发布。
2. Server 拒绝 HTML、危险链接、重复条目键、非法状态和无效媒体。
3. 公开与预览响应都能解析已选择的 COS 图片。
4. 旧首页发布版本无数据迁移也能正常渲染；保存新版草稿后进入完整动态闭环。
