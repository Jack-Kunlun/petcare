# Triage 标签

工程技能使用五种标准分流角色。本文件将这些角色映射到当前项目 Issue 跟踪系统中的实际标签。

| 标准角色          | GitHub 标签       | 含义                          |
| ----------------- | ----------------- | ----------------------------- |
| `needs-triage`    | `needs-triage`    | 等待维护者评估                |
| `needs-info`      | `needs-info`      | 等待报告者提供更多信息        |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可以交由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策            |
| `wontfix`         | `wontfix`         | 已决定不处理                  |

当技能提到某种分流角色时，使用表格中对应的 GitHub 标签。

如果项目以后调整标签命名，只需修改“GitHub 标签”列。
